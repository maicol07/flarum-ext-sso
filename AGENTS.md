# flarum-ext-sso

Flarum 2 extension providing SSO (JWT login endpoint, provider mode syncing users to client forums). PHP ≥ 8.3 backend in `src/`, TypeScript frontend in `js/`.

## Tooling

- Rector: `vendor/bin/rector process` (config in `rector.php`, PHP 8.3 set).
- `composer.lock` is gitignored.

## Changelog & releases

- Commits follow Conventional Commits with a Unicode gitmoji after the colon (`feat: ✨ ...`).
- Changelog is generated by git-cliff (`cliff.toml`).
- Publishing a GitHub release triggers `.github/workflows/release.yml`, which writes the release notes and commits the regenerated `CHANGELOG.md` to the default branch as `docs(changelog): ...` (skipped by git-cliff).
- Local preview: `GITHUB_REPO=maicol07/flarum-ext-sso git cliff --unreleased`.
